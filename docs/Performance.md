# Performance Report

## Current opportunities
- Frontend bundle should be kept lean through code splitting and lazy loading.
- API responses should use pagination and selective field projection.
- MongoDB indexes should be reviewed for bookings, routes, and user lookups.

## Recommended actions
- Cache hot routes and dashboard summaries.
- Use lazy loading for larger screens and tour galleries.
- Compress assets and enable production optimizations in Vite.
